# 📌 Project Overview

Customer churn is one of the biggest challenges faced by businesses today. This project helps organizations identify customers who are likely to leave the company by using Machine Learning algorithms and data-driven insights.

The dashboard provides:

✅ Real-time churn prediction
✅ Business insights & recommendations
✅ Interactive visualizations
✅ High-risk customer identification
✅ Downloadable analytics reports
✅ Beautiful premium UI dashboard using Gradio

---

# 🎯 Objectives

* Predict whether a customer will churn or not
* Analyze customer behavior patterns
* Identify high-risk customers
* Help businesses improve customer retention
* Build a professional end-to-end ML dashboard

## 🔹 Data Preprocessing

* Train-Test Split

## 🔹 Model Training

Used:

* Gradient Boosting Classifier

Evaluated using:
